# Показания счётчиков — правила проекта

Портфолио-концепт: эмоциональный дизайн экранов ввода показаний счётчиков
в приложении управляющей компании. Автор — дизайнер Ульяна. Общаться по-русски,
объяснять просто и по шагам. Исходные макеты — в Figma, перенесены 1:1.
**Не меняй согласованные решения без просьбы.** Скриншоты всех состояний — в `screens/`.

Чистый HTML + CSS + JS без сборки: `index.html`, `styles.css`, `app.js` (логика), `bg.js` (живой фон).

## Экраны
- Телефон 402×874, радиус 54, фон `#141414`. `fit()` масштабирует под окно.
- На компьютере под телефоном подпись «Автор @yulianiaa» (ссылка на t.me/yulianiaa, `#4DA3FF`), её позицию считает `fit()`; на смартфоне скрыта.
- **Список** «Показания за ноябрь» (Medium 28/32), подзаголовок «Передайте показания до 20 ноября» (Regular 16/24, `#999`).
  - Вода: «Холодная вода», «Горячая вода» — отдельные ячейки. Электричество: одна карточка, строки «День», «Ночь».
  - В начале все значения пустые. После сохранения значение появляется справа в строке (`#999`).
  - «Передать показания» активна, когда сохранено хотя бы одно значение.
- **Экран ввода**: стеклянные кнопки «Назад» и «Фонарик», заголовок + номер, «Текущие показания», число 96px, единица, подсказка, клавиатура 3×4, «Сохранить».
- Хоум-индикатора нет.

## На смартфоне — как настоящее приложение
- Включается при `max-width: 500px` + сенсорный экран: класс `.app` на `<html>`. На компьютере всё как в макете.
- Без рамки и нарисованного статус-бара (виден настоящий), во весь экран. `fit()` растягивает по ширине и считает позиции:
  `--nav-top` — под safe-area, `--btn-top` / `--kb-top` — от низа, `--read-top` — по центру между шапкой и клавиатурой. Значения по умолчанию = макет.
- Фон 402×874 стоит по центру экрана по вертикали.
- Нет зума и выделения текста; мета-теги для «На экран „Домой“» (открывается без адресной строки).

## Флоу
1. Вода — **каждый счётчик отдельно**: «Сохранить» → назад в список. Автопереключения холодная → горячая нет.
2. Электричество: «Сохранить» на «День» → сразу открывается «Ночь» (цвет перетекает за 0.6 с); «Сохранить» на «Ночь» → в список.
3. Переход список → ввод: список гаснет с блюром (220 мс), затем экран ввода проявляется (300 мс). Обратно: 180 + 240 мс.
4. При возврате в список введённое число **не обнуляется**, пока экран гаснет; поле очищается при следующем открытии счётчика.

## Правила ввода
- Пусто: «0» белым 60%, подсказка «Предыдущие показания — X», белый 60%.
- Значение ≥ предыдущего: «Текущий расход — X», цвет акцента; «Сохранить» активна (`#f5f5f5`, текст `#141414`).
- Значение < предыдущего: «Новые показания должны быть не ниже предыдущих» (неразрывный пробел после «не»); кнопка неактивна (`#232323` / `#7b7b7b`).
- Запятая одна и не первой; максимум 7 цифр; мигающий курсор после числа.
- С компьютера: цифры, `,` / `.`, Backspace, Enter, Esc.

## Типографика и элементы
- Весь текст — Medeo Sans (`fonts/`, коммерческая лицензия — проверить web-лицензию перед публикацией).
- Medium: заголовок списка, заголовки групп, заголовок экрана ввода, кнопки, клавиши. Regular: всё остальное (у текста всегда явно указывать начертание).
- Курсор мыши — белый кружок 16px (`#f5f5f5`, без обводки, мягкая тень без сдвига, равномерно вокруг: размытие 2.5, чёрный 25%) везде, и над кнопками тоже: `--cursor` в `styles.css`.
- Клавиши — «воздушное» стекло: заливка белый 4%, inset-обводка 4%, верхний блик 10%, нажатие 14%. Отклонено: плотные графитовые клавиши, чёрная обводка, оранжевая CTA.

## Живой фон (bg.js)
Под экраном ввода: два маленьких canvas → лёгкая белая вуаль 1.5% → затемнение за цифрами (`.quiet`) → зерно `grain.png` (overlay, 12%) → `#cover` для переходов.

**Вода — ленты.** 3 шёлковые ленты, холодная: синие (`COLD`), горячая: красные (`HOT`). Поток замедляется с каждой цифрой до ×0.5 за 5 цифр; после сохранения — ускорение ×1.4 на 1.2 с.

**Электричество — лучи** «песочными часами», двигаются **сами по себе** по реальному времени (не зависят от ввода).
- 3 веера (главный всегда ярче), 3 мягких штриха внутри своих вееров, 3 половинки лучей (идут в одну сторону, проявляются и гаснут — видно 1–3).
- Веера раздвигаются (`spread`), изгиб общий, поворот ±0.33 рад — лучи не сливаются, не превращаются в «зонтик» и не ложатся по диагонали в две полосы.
- Точка схождения приглушена (ядро радиус 30, яркость 0.12).
- День — светлый тёплый (`#ffd49a`, `#ffdcc8`), ярче ночи в 1.35 раза. Ночь — сиреневая (`#8d87c6`, `#666b9c`) — **согласована как идеальная, не трогать**.
- Нажатие клавиши — мягкий блик по штриху (~1 с), не вспышка.
- Скорость: `RAY.speed` в `app.js` (1 = норма).

## Производительность — важно для телефона
- Фон рисуется на canvas в 1/8 (`#bgSoft`, CSS blur 22px вода / 16px лучи) и 1/4 разрешения (`#bgSharp`, blur 7px) и растягивается — размытие почти бесплатное, ~30 к/с.
- **Не возвращать** SVG-фильтры (feGaussianBlur), SVG-зерно и `backdrop-filter` поверх анимации — на iPhone анимация застывала.
- Если нужен `backdrop-filter`: у предков не должно быть `filter` или `opacity < 1`, иначе он ломается и даёт вспышку.
