# Показания счётчиков — концепт с эмоциональным дизайном

Интерактивный прототип экранов передачи показаний (управляющая компания).
Под матовым стеклом текут ленты света: пока вводишь цифры, поток затихает,
после «Сохранить» холодная вода перетекает в горячую.

Чистый HTML + CSS + JS, без сборки и зависимостей.

## Файлы

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка: телефон, список, экран ввода, холст для лент |
| `styles.css` | Все стили и цвета |
| `app.js` | Логика: клавиатура, проверки, переходы, анимация лент. Настройки — в самом верху (`CONFIG`) |
| `fonts/` | Шрифт Medeo Sans |
| `CONTEXT.md` | Все дизайн-решения — для Claude в VS Code |

## 1. Открыть в VS Code

1. Распакуйте архив в удобную папку, например «Документы/meters-app».
2. В VS Code: **File → Open Folder…** → выберите папку `meters-app` → **Open**.
3. Посмотреть прототип: дважды кликните `index.html` в Finder/Проводнике — откроется в браузере.

Удобнее с автообновлением:
1. Слева значок квадратиков **Extensions** → найдите **Live Server** → **Install**.
2. Правый клик по `index.html` → **Open with Live Server**. Теперь при сохранении файла страница обновляется сама.

## 2. Опубликовать на GitHub (самый простой путь)

Нужен аккаунт на github.com.

1. В VS Code слева значок с веточками — **Source Control** (или `Ctrl+Shift+G` / `Cmd+Shift+G`).
2. Нажмите синюю кнопку **Publish to GitHub**.
   - Если VS Code попросит войти в GitHub — нажмите **Allow** и подтвердите в браузере.
3. Сверху появится выбор — нажмите **Publish to GitHub public repository**.
4. Если спросит, какие файлы включить — оставьте все галочки → **OK**.

Готово: VS Code сам сделал первый коммит и загрузил проект на GitHub.

## 3. Включить публичную страницу (GitHub Pages)

1. Откройте репозиторий на github.com (VS Code покажет кнопку **Open on GitHub**).
2. Вкладка **Settings** → слева **Pages**.
3. В блоке **Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, папка — **/ (root)** → **Save**.
4. Через 1–2 минуты обновите страницу — сверху появится ссылка вида
   `https://ваш-логин.github.io/meters-app/`. Её можно вставлять в портфолио.

## 4. Как сохранять изменения дальше

1. Поменяли что-то в файлах → **Source Control**.
2. В поле сверху напишите, что изменили (например, «Сделала ленты ярче»).
3. **Commit** → затем **Sync Changes**.
4. Сайт обновится сам через минуту.

## 5. Работа с Claude в VS Code

Попросите Claude сначала прочитать `CONTEXT.md` — там все решения по дизайну,
цвета и логика, чтобы он не сломал уже согласованное.

## ⚠️ Шрифт

Medeo Sans — коммерческий шрифт. При публикации файл шрифта из `fonts/` станет
доступен всем, кто откроет сайт. Проверьте, разрешает ли ваша лицензия
использование на сайтах (web-лицензия). Если нет — удалите папку `fonts/`
перед публикацией: прототип покажется системным шрифтом.
