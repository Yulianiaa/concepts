# Контекст проекта (для Claude)

Портфолио-концепт: эмоциональный дизайн экранов ввода показаний счётчиков
в приложении управляющей компании. Автор — дизайнер, общается по-русски,
нужны простые пошаговые объяснения. Исходные макеты — в Figma, отсюда
перенесены 1:1. Не меняй согласованные решения без просьбы.

## Структура
- Телефон 402×874, радиус 54, фон `#141414`. `fit()` масштабирует под окно.
- На смартфоне (`max-width: 500px` + сенсорный экран) класс `.app` на `<html>`: без рамки и нарисованного статус-бара, во весь экран. `fit()` растягивает по ширине и считает позиции (`--nav-top` под safe-area, `--btn-top`/`--kb-top` от низа, `--read-top` — по центру между шапкой и клавиатурой). На компьютере значения по умолчанию = макет.
- `#listScreen` — список «Показания за ноябрь»: Вода (холодная, горячая), Электричество (день 862, ночь 254 — уже введены).
- `#inputScreen` — ввод. Под ним `#inputBg`: SVG-ленты → `.frost` (backdrop-filter blur 28px) → `.quiet` (затемнение за цифрами) → `.grain` (шум, overlay 0.34) → `#cover`.

## Флоу
1. Тап по «Холодная вода» → экран ввода (холодные ленты).
2. «Сохранить» → остаёмся на экране, становится «Горячая вода»; ленты перекрашиваются в красные за 0.6 с, поток ускоряется ×1.4 на 1.2 с.
3. «Сохранить» на горячей → назад в список, значения проставлены.
4. Тап по «Горячая вода» в списке → сразу горячий экран.

## Правила ввода
- Пусто: «0» белым 50% (`.num.empty`), подсказка «Предыдущие показания — 67,68 м³» (горячая: 29 м³), белый 50%.
- Значение ≥ предыдущего: «Текущий расход — X м³», цвет `#c4e9fb` (холодная) / `#ffc9a8` (горячая); кнопка активна.
- Значение < предыдущего: «Новые показания должны быть не ниже предыдущих» (неразрывный пробел после «не»), кнопка неактивна.
- Запятая одна, не первой; максимум 7 цифр. Мигающий курсор после числа.
- Физическая клавиатура: цифры, `,`/`.`, Backspace, Enter, Esc.

## Визуальные решения (согласованы)
- Весь текст — Medeo Sans. Заголовок экрана и «Показания за ноябрь» — Medium; подписи строк — Regular.
- Основная кнопка `#f5f5f5`, текст `#141414`; disabled `#232323` / `#7b7b7b`. Оранжевый CTA отклонён.
- Клавиши — «воздушное» стекло: заливка белый 4%, inset-обводка 4%, верхний блик 10%, нажатие 14%. Плотные графитовые клавиши и чёрная обводка отклонены.
- Ленты: каждая = чёткая кромка (clipPath) + размытые deep (blur 50) и bright (blur 30). Цвета/параметры — в `app.js` (`COLD`, `HOT`, `RIBBONS`).
- Поток замедляется с каждой цифрой до ×0.5 за 5 цифр.
- Апп-бар списка: иконка «Назад» в 12px от левого края экрана (кнопка 40×40 стоит на left: 4px).
- Хоум-индикатора на экранах нет — убран намеренно.

## Важно технически
- `backdrop-filter` ломается, если у предка есть `filter` или `opacity < 1`. Поэтому переходы: список гаснет + блюр, затем `#cover` (#141414) уходит и UI проявляется; opacity только на контейнере UI, не на фоне. Иначе — вспышка и видны ленты.
- Анимация на requestAnimationFrame, ленты ~30 fps и только когда виден экран ввода.
