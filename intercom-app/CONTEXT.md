# Экран домофона — контекст проекта

UI-концепт экрана входящего вызова домофона для портфолио (кейс). Мобильный экран iPhone 16 Pro, 402 × 874.

Исходники дизайна: Figma, файл `visual`, секция «Section 1»
https://www.figma.com/design/ukWE8mPgxsfA5ZodidL5sS/visual?node-id=75-1282

## Задача и инсайт

Исходный экран домофона (приложение управляющей компании) построен как телефонный звонок: маленькое видео, крупная кнопка «Ответить», непонятная «Закрыть» и красный замок, который на самом деле открывает дверь.

Реальное поведение пользователя: посмотреть на видео, узнать человека и сразу открыть дверь. Разговаривают по домофону редко. Поэтому:

- видео — на весь экран, это главная информация;
- главное действие — «Открыть» (оранжевая, по центру, под большим пальцем);
- «Ответить» и «Отклонить» — второстепенные стеклянные круги по бокам;
- после нажатия — явная обратная связь «Дверь открыта».

## Сценарий (основной)

1. **Входящий вызов** — статус «● Звонок на домофон» (красная точка live), заголовок «Вход со двора», снизу: микрофон · «Открыть» · крестик.
2. **Открываем** — после тапа по «Открыть»: боковые кнопки исчезают, оранжевая кнопка сжимается в круг 64 × 64 с лоадером; статус меняется на «Звонок завершен», точка исчезает.
3. **Дверь открыта** — кнопка растягивается на всю ширину и становится светлой (#F5F5F5), появляется замок и текст «Дверь открыта» (#141414).
4. **Замок открывается** — дужка приподнимается и откидывается вбок.

Сценарий с разговором (ответить → таймер → открыть) в кейс не входит. Что происходит после «Дверь открыта» (автозакрытие экрана), не показываем.

## Дизайн-токены

| Токен | Значение | Где |
|---|---|---|
| Accent | `#FF5C00` | «Открыть», круг загрузки |
| Success bg | `#F5F5F5` | итоговая плашка |
| Success fg | `#141414` | текст и замок на плашке |
| Text | `#FFFFFF` | заголовок |
| Text secondary | `#F5F5F5` | статус |
| Live | `#FF1016` | точка 8 × 8 |
| Glass | белый 12% заливка + обводка 1px белый 12%, background blur 20 | боковые кнопки |
| Top gradient | 178px, `rgba(5,5,5,.6)` → прозрачный | под статус-баром и заголовком |

Типографика — **Geologica** (Google Fonts):

- Заголовок: ExtraBold 800, 52/52, трекинг −6% (≈ −3.1px), в одну строку.
- Статус и текст кнопок: Regular 400, 24/32.

Сетка и размеры:

- Боковые поля 24, ширина контента 354.
- Шапка: `top 94`, статус 32px высотой, отступ точка–текст 10.
- Кнопки: `top 768`, высота 64, круги 64 × 64, «Открыть» 194 × 64, между кнопками 16.
- Иконки 32 × 32, отступ иконка–текст на плашке 8.
- Статус-бар: iOS kit, 62px, время 13:00.

## Анимация (тайминги)

| Шаг | Что происходит | Длительность |
|---|---|---|
| Тап «Открыть» | боковые кнопки: opacity → 0, scale → 0.6 | 0.25–0.3s |
| | кнопка: ширина 194 → 64 | 0.45s, `cubic-bezier(.65,0,.35,1)` |
| | текст «Открыть» гаснет, лоадер появляется | 0.2s, задержка 0.3s |
| Загрузка | три точки по очереди «ныряют» вниз на 5px | цикл 0.9s, сдвиг 0.15s |
| Через 1.8s | ширина 64 → 354, фон #FF5C00 → #F5F5F5 | 0.45s |
| | замок и «Дверь открыта» появляются | 0.3s, задержка 0.35s |
| | дужка: вверх на 3px, затем отражается вбок | 0.55s, задержка 0.9s |

Дополнительно в интерактивном прототипе (`intro: true`):

| Что | Как | Длительность |
|---|---|---|
| Появление вызова | фото: из размытия и scale 1.08; статус-бар и градиент проявляются | 1s / 0.6s, задержка 0.2s |
| | шапка и кнопки проявляются на месте, без сдвига (прозрачность — у каждой кнопки отдельно, иначе стекло не размывается до конца анимации) | 0.6s, одновременно, задержка 0.35s |
| Точка live | пульсирующее кольцо 8px | цикл 1.6s |
| Смена статуса | новый текст проявляется снизу на 6px | 0.35s |
| Нажатие | «Открыть» scale 0.96, круги scale 0.92 | 0.15s |

Есть `prefers-reduced-motion`: анимации сводятся к мгновенной смене состояний.

## Файлы

```
index.html            — интерактивный прототип: на компьютере в рамке iPhone, на смартфоне во весь экран как приложение (как в meters-app); повтор — тап по плашке «Дверь открыта»; ниже галерея 4 статичных экранов (на смартфоне скрыта)
src/styles.css        — токены (CSS-переменные) и стили компонента
src/intercom.js       — createIntercomScreen(mount, { state, interactive, lockOpen, entrance, photo, intro })
assets/bg-yard.jpg    — фото (временное, 402 × 874)
assets/icons/*.svg    — иконки из Figma: mic, close, loading, lock, lock-open
```

Замок в анимации собран из частей (корпус, скважина, дужка), чтобы дужка могла двигаться. `lock.svg` и `lock-open.svg` — оригинальные иконки из Figma для справки.

## Как открыть

Открыть `index.html` в браузере (работает и с диска). Для правок удобно расширение **Live Server** в VS Code: правой кнопкой по `index.html` → «Open with Live Server».

## Открытые вопросы

- Фото временное: селфи во дворе. Нужен кадр «с камеры у двери» (фиксированная камера на уровне головы), будет сгенерирован отдельно. Заменить `assets/bg-yard.jpg`, размер 402 × 874 или кратный (1206 × 2622 для @3x).
- Длинные названия входов («Этаж 5 · секция») в 52px не помещаются в одну строку — нужно правило: уменьшать кегль для длинных названий.
- Время в статус-баре — текст системным шрифтом; на устройствах без SF Pro будет подставлен другой шрифт.
